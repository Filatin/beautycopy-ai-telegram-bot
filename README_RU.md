# BeautyCopy: распознавание фото

Фото духов → подтверждение или исправление названия → язык, формат, стиль → готовый текст.
Можно сначала выбрать формат, затем отправить фото. Сохранённый продукт используется
для других форматов. Кнопка New product / Nowy produkt или /new начинает новый товар.

Если этикетка не читается, узнаваемый флакон можно определить предположительно, с предупреждением
и обязательным подтверждением. При низкой уверенности бот просит полное название. Цвет флакона сам по себе
не подтверждает модель, объём или концентрацию. Функция создаёт тексты; поиск в интернете,
изменение фото и создание рекламных картинок в неё не входят.

При обновлении существующего Cloudflare Worker сохраняются имя сервиса, webhook и секреты.
SQLite Durable Objects хранят выбранный продукт и очередь сообщений. Байты фото
в диалоге не сохраняются. После обработки остаются название, этикетка и внешний вид;
сессия удаляется через 24 часа бездействия. Новое фото заменяет старый продукт, в том
числе при ошибке распознавания.

Проверено: 21 тест с имитацией Telegram/AI и сборка Wrangler. Точность реальных фото
проверяется отдельно. Бесплатное использование зависит от квот Cloudflare.

Развёртывание:
1. Войти в тот же Cloudflare: npx wrangler login.
2. Выполнить npm ci, npm run check, npm test и npm run deploy.
3. Проверить Worker: version = 2.0.0-photo, configured = true, sessions = true.
4. В Telegram: /start → фото одного флакона → подтверждение → формат.
5. Проверить нечёткое фото, исправление названия и смену продукта.

Подробности и официальные источники — в README.md.
